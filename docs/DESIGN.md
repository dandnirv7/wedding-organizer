# Wedding Organizer — Design System & Direction

## 1. Project Overview

### Project

Wedding Organizer Landing Page

### Business Category

Wedding Organizer / Wedding Service

### Primary Objective

Build a visually compelling landing page that:

- Creates an emotional first impression
- Communicates the quality of the wedding experience
- Establishes trust through real wedding work
- Clearly communicates services and capabilities
- Reduces uncertainty around the planning process
- Drives prospective couples toward consultation or inquiry

### Primary Conversion

**Start Planning / Consultation**

### Secondary Conversions

- View Real Weddings
- Explore Services
- View Packages
- Contact via WhatsApp
- Submit Wedding Inquiry

---

# 2. Design Direction

## 2.1 Core Design Character

The visual identity should communicate:

- Warm
- Emotional
- Elegant
- Human
- Editorial
- Timeless
- Professional
- Celebratory

The website should feel like an **editorial wedding experience supported by professional wedding planning expertise**, rather than a conventional corporate event-management website.

---

## 2.2 Visual Keywords

```
Editorial
Warm
Romantic
Timeless
Human
Elegant
Celebratory
Authentic
Refined
Personal
```

---

## 2.3 Brand Impression

Visitors should ideally perceive the brand as:

> Experienced enough to handle the complexity of a wedding, while personal enough to make the celebration feel uniquely theirs.

The design should communicate confidence without becoming overly corporate, and elegance without becoming excessively luxurious or decorative.

---

## 2.4 Design Principles

### 01 — Emotion First

The website should allow visitors to feel the wedding experience before asking them to understand the service.

### 02 — Photography Is a Primary Communication Asset

Real wedding photography and video are not decorative elements. They are major proof of the brand's capability and experience.

### 03 — Elegant, Not Excessive

Elegance should come from:

- Typography
- Composition
- Whitespace
- Photography
- Proportion
- Restraint

Avoid relying on excessive decorative elements to communicate elegance.

### 04 — Trust Through Proof

Use real weddings, testimonials, experience, process, and service information to establish credibility.

### 05 — Clarity Over Decoration

Every visual element should support at least one of these purposes:

- Emotion
- Understanding
- Trust
- Conversion

### 06 — Human Over Corporate

Copy, photography, and visual treatment should maintain a sense of human connection.

### 07 — Guide, Don't Pressure

The interface should naturally guide visitors toward consultation without relying on aggressive conversion patterns.

---

# 3\. Brand & Visual Direction

## 3.1 Overall Direction

The design should combine:

```
Editorial Photography
        +
Elegant Serif Typography
        +
Modern Sans-serif UI
        +
Warm Neutral Palette
        +
Generous Whitespace
        +
Minimal UI
```

---

## 3.2 Visual Balance

The interface should remain predominantly neutral.

Recommended visual balance:

```
70% — Neutral surfaces
20% — Photography / imagery
10% — Accent / decorative color
```

Photography should provide most of the visual color and emotional richness.

---

## 3.3 Avoid

The following visual directions should generally be avoided:

- Generic corporate aesthetic
- SaaS-style interface
- Excessive rounded cards
- Excessive use of gold
- Metallic gold gradients
- Heavy shadows
- Excessive glassmorphism
- Excessive gradients
- Overly decorative borders
- Excessive floral graphics
- Overly ornamental UI
- Generic stock wedding photography
- Excessive animations
- Fast or playful transitions
- Dense information layouts
- Excessive use of boxed content

---

---

## 4.2 Charcoal

```
#1E1D1B
```

Primary dark color.

Use for:

- Headings
- Body text where strong contrast is required
- Navigation
- Primary buttons
- Footer background
- Icons
- Important UI elements

Avoid pure black `#000000` as the dominant dark color unless required for accessibility or media treatment.

---

## 4.3 Warm Ivory

```
#F7F3EE
```

Primary background color.

Use for:

- Main page background
- Editorial sections
- Content sections
- Large whitespace areas

The ivory background should establish warmth without making the website feel heavily beige.

---

## 4.4 Soft Beige

```
#E8DED2
```

Secondary surface color.

Use for:

- Supporting sections
- Subtle content blocks
- Service areas
- Testimonial backgrounds
- Secondary visual separation

Do not use as the primary page background.

---

## 4.5 Champagne

```
#B69B72
```

Accent color.

Use sparingly for:

- Decorative lines
- Small labels
- Eyebrow text
- Icons
- Subtle highlights
- Hover states
- Selected states
- Small visual details

Avoid using champagne for:

- Large backgrounds
- Large text blocks
- Every CTA
- Excessive borders
- Large decorative areas

The accent should feel understated rather than metallic or flashy.

---

## 4.6 White

```
#FFFFFF
```

Use for:

- Text on dark backgrounds
- Light cards where necessary
- High-contrast areas
- Navigation overlays on dark imagery

## 5.1 Typography Pairing

### Display Typeface

**Cormorant Garamond**

- Emotional expression
- Editorial character
- Hero headlines
- Major section headings
- Pull quotes
- Large statements

Character:

```
Elegant
Editorial
Romantic
Timeless
Refined
```

---

### UI / Body Typeface

**Manrope**

Purpose:

- Body copy
- Navigation
- Buttons
- Labels
- Metadata
- Forms
- Supporting information

Character:

```
Modern
Clean
Neutral
Readable
Functional
```

---

## 5.2 Typography Principle

Use the serif typeface to create emotion and personality.

Use the sans-serif typeface to maintain clarity and usability.

```
Cormorant Garamond = Emotion
Manrope            = Clarity
```

# 7\. Typography Rules

## Headlines

Headlines should generally be short and emotionally driven.

Preferred:

> Your Story, Beautifully Celebrated.

Avoid overly descriptive headlines that create large blocks of serif text.

---

## Body Copy

Body copy should remain concise.

Recommended maximum line length:

```
60–75 characters
```

Long paragraphs should be divided into smaller blocks.

---

## Eyebrow Text

Eyebrows may use:

- Uppercase
- Increased letter spacing
- Manrope
- 11–12px
- Medium or semibold weight

Example:

```
OUR WEDDINGS
```

---

## Button Text

Use short action-oriented labels:

```
START PLANNING
VIEW OUR WEDDINGS
EXPLORE SERVICES
GET IN TOUCH
```

Avoid generic labels when a more descriptive action is available.

## 11.1 Image Philosophy

Photography is one of the most important elements of the design.

Images should communicate:

- Real emotion
- Human connection
- Celebration
- Detail
- Atmosphere
- Cultural identity
- Wedding quality
- Professional execution

## 11.2 Preferred Photography

Prioritize:

- Real weddings
- Real couples
- Real ceremonies
- Real decorations
- Real preparation moments
- Candid interactions
- Emotional moments
- Detail shots
- Venue atmosphere

---

## 11.3 Avoid

- Generic stock wedding photography
- Overly staged stock images
- Excessive filters
- Heavy color grading

# 12\. Hero Video

## 12.1 Hero Direction

The hero should use a cinematic wedding video as the primary visual.

The video should communicate the quality and emotional atmosphere of the service immediately.

---

## 12.2 Video Behavior

The hero video should:

- Autoplay
- Be muted by default
- Loop
- Use high-quality footage
- Maintain appropriate contrast for text
- Load efficiently
- Respect reduced-motion preferences

---

## 12.3 First 3–5 Seconds

The opening sequence should immediately communicate:

- Wedding atmosphere
- Couple
- Human emotion
- Venue or decoration
- Quality of execution

Avoid opening with:

- Empty venue shots
- Slow logo animations
- Abstract footage
- Long establishing shots without human context

---

## 12.4 Hero Overlay

Use a subtle overlay only when necessary to maintain text readability.

Avoid heavy dark overlays that significantly alter the photography.

---

## 12.5 Hero Copy

Hero copy should remain concise.

Recommended structure:

```
Eyebrow
Headline
Short supporting statement
Primary CTA
Secondary CTA
```

Example:

```
WEDDING ORGANIZER

Your Story,
Beautifully Celebrated.

Thoughtfully planned celebrations,
crafted around your story.

START PLANNING
VIEW OUR WEDDINGS
```

Copy should be finalized based on the client's actual positioning and brand voice.


---

# 14\. Shadows

Shadows should be minimal.

Preferred:

```
None
or
Very subtle shadow
```

Avoid:

- Heavy drop shadows
- Floating card effects
- Strong elevation systems
- Excessive layered shadows

The design should rely on:

- Contrast
- Spacing
- Photography
- Typography
- Background changes

rather than shadows to establish hierarchy.

# 24\. Motion & Interaction

## 24.1 Motion Character

Motion should feel:

```
Slow
Elegant
Intentional
Subtle
Cinematic
```

---

## 24.2 Avoid

- Bouncing animations
- Excessive parallax
- Fast transitions
- Gamified interactions
- Excessive scrolling effects
- Continuous motion
- Decorative animations without purpose

---

## 24.3 Timing

### Micro Interaction

```
150–250ms
```

### Standard Transition

```
300–500ms
```

### Image Reveal

```
600–900ms
```

### Editorial / Hero Transition

```
800–1200ms
```

Motion should support the photography and content hierarchy rather than compete with them.

---

# 25\. Scroll Behavior

Scrolling should feel continuous and editorial.

Recommended:

- Subtle image reveals
- Gentle fade/slide transitions
- Controlled image movement
- Smooth section transitions

Avoid:

- Aggressive scroll hijacking
- Excessive horizontal scrolling
- Multiple competing animations
- Long loading transitions

## 26.1 Desktop

```
1280px+
```

Characteristics:

- Full-width imagery
- Generous whitespace
- Multi-column layouts
- Large editorial compositions

---

## 26.2 Tablet

Breakpoint:

```
768–1279px
```

Characteristics:

- 8-column grid
- Reduced typography
- Reduced section spacing
- Simplified compositions
- Controlled image ratios

---

## 26.3 Mobile

Breakpoint:

```
<768px
```

Characteristics:

- 4-column grid
- 20–24px side padding
- Reduced hero typography
- Stacked layouts
- Simplified navigation
- Larger touch targets
- Prominent CTA

---

# 27\. Mobile Hero

The hero video remains important on mobile but must prioritize:

- Readability
- Loading performance
- Subject visibility
- CTA accessibility

The crop should preserve the most important subject rather than simply shrinking the desktop composition.

If video performance becomes an issue, use an optimized poster image or mobile-specific video asset.

---

# 28\. Accessibility

## 28.1 Contrast

Text should maintain sufficient contrast against its background.

Do not place important text directly over visually complex imagery without appropriate contrast treatment.

---

## 28.2 Typography

Body text should generally remain at:

```
16px minimum
```

unless there is a specific visual or contextual reason to use smaller text.

---

## 28.3 Touch Targets

Interactive elements should provide comfortable touch targets on mobile.

Recommended minimum:

```
44 × 44px
```

---

## 28.4 Motion Preferences

Respect:

```
prefers-reduced-motion
```

When reduced motion is enabled:

- Reduce or remove non-essential animation
- Disable aggressive parallax
- Minimize image movement
- Keep content fully accessible

---

## 28.5 Video Accessibility

The hero video must not be required to understand the primary message.

The essential message should always be available through text.

Video should be:

- Muted by default
- Non-essential to comprehension
- Properly optimized
- Respectful of reduced-motion preferences

---

Lead with the experience and outcome before explaining operational details.

---

## Specific Before Generic

Prefer:

> Thoughtfully planned celebrations for your most meaningful moments.

Over:

> We provide professional wedding organizer services.

---

## Benefit Before Feature

Prefer:

> Enjoy your wedding day while we coordinate every detail.

Over:

> We provide wedding day coordination services.

---

## Authenticity Over Marketing Language

Avoid excessive use of:

```
Best
Number One
Luxury
Premium
World-Class
Unforgettable
Perfect
```

unless these claims are genuinely supported by the client's positioning and evidence.

# 36\. Design QA Checklist

Before considering a section complete, verify:

## Visual

- [ ] Does the section feel warm and editorial?
- [ ] Is the typography hierarchy clear?
- [ ] Is whitespace sufficient?
- [ ] Is the accent color used sparingly?
- [ ] Does photography remain the visual focus?
- [ ] Are there unnecessary decorative elements?

## UX

- [ ] Is the purpose of the section immediately understandable?
- [ ] Is the CTA clear where needed?
- [ ] Does the content flow naturally?
- [ ] Does the section reduce uncertainty?
- [ ] Does it support the overall conversion journey?

## Responsive

- [ ] Does the layout work on desktop?
- [ ] Does it work on tablet?
- [ ] Does it work on mobile?
- [ ] Does typography remain readable?
- [ ] Are touch targets sufficiently large?
- [ ] Does image cropping preserve important subjects?

## Accessibility

- [ ] Is text contrast sufficient?
- [ ] Is essential information available without video?
- [ ] Are animations non-essential?
- [ ] Is reduced motion respected?
- [ ] Are interactive elements accessible?

# 37\. Final Design Principles

The final design should consistently communicate:

> **Your wedding is the story.\
> We make sure every detail comes together beautifully.**

The interface should feel:

```
Warm, not cold.
Elegant, not excessive.
Emotional, not dramatic.
Professional, not corporate.
Editorial, not templated.
Personal, not generic.
Confident, not aggressive.
```

Every design decision should ultimately support one of four goals:

```
EMOTION
TRUST
CLARITY
CONVERSION
```

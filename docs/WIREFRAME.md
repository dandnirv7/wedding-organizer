# WIREFRAME.md

# Wedding Organizer Landing Page — Editorial / Cinematic Experience

## 1\. Wireframe Overview

### Page Type

Single-page experiential marketing website.

### Primary Objective

Membangun pengalaman digital yang membuat calon pengantin:

```
FEEL
↓
DISCOVER
↓
UNDERSTAND
↓
TRUST
↓
IMAGINE
↓
ACT
```

Website tidak diposisikan sebagai katalog layanan Wedding Organizer.

Website diposisikan sebagai **digital editorial experience** yang memperlihatkan:

- cerita
- atmosfer
- craftsmanship
- proses
- manusia di balik wedding
- hasil pekerjaan
- pengalaman client

### Primary Conversion

**Mulai Konsultasi**

### Secondary Conversion

**Explore Wedding Stories**

---

Video harus terasa seperti **trailer sebuah wedding story**, bukan footage random.

# 35\. Motion Direction

Motion language:

```
Slow
Elegant
Cinematic
Intentional
```

Recommended:

```
Fade
Reveal
Slow Scale
Mask Reveal
Image Crop
Parallax ringan
Text Transition
```

Avoid:

```
Bounce
Elastic
Fast Zoom
Excessive Parallax
Continuous Floating
Over-animated Cursor
```
